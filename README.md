# Tripp · Шинэ жилийн аялал

2026.12.24 – 2027.01.04: Улаанбаатар → Замын-Үүд → Хөх хот → Шанхай → Пхукет → Бангкок → Улаанбаатар.

Дөрвөн хэсэгтэй:

- **Өнөөдөр:** өдрийн мөр, аялал / шинэ жил хүртэлх тоолуур, тухайн өдрийн цагийн хуваарь. Алхам бүрийг ✓ дарж тэмдэглэнэ, тээвэр, буудал захиалсан эсэх нь шууд харагдана. Харандаагаар өдрийн гарчиг, хонох газар, тээврийг засна.
- **Маршрут:** гэрлэн мөрт газрын зураг, хотууд, үзэх газрууд (❤ саналтай), захиалга (тээвэр, буудал, бусад).
- **Мөнгө:** нийтийн зардал (₮ / ¥ / ฿ / $), хэн хэнд хэд өгөх (Хаах товчоор тооцоо хаана), төсөв, ханш.
- **Баг:** хүмүүс, хэн онлайн, мэдэгдэл, урилга, бэлтгэлийн жагсаалт, ачаа, хэрэгтэй мэдээлэл, Шөнө / Өдөр өнгө.

## Тасалбар, баримт (офлайн)

Захиалга бүр дээр тасалбар, QR код, баталгааны зураг эсвэл PDF хавсаргана (Маршрут → Захиалга, эсвэл + товч → Захиалга, тасалбар). Даатгал, eSIM, Диснейн тасалбар гэх мэтийг «Баримт» болгон нэмнэ.

- Файлууд Supabase-ийн хаалттай `tripp-files` санд хадгалагдаж, урилгын холбоостой бүлгийн гишүүд л харна.
- Апп сүлжээтэй үедээ **бүх хүний утсанд бүх файлыг** татаж хадгална. Нисэх онгоцны буудал, хил дээр сүлжээгүй ч дээд талын 🎫 товчоор шууд нээгдэнэ.
- PDF-ийг хуудас бүрээр нь зураг болгон хадгалдаг тул ямар ч утсан дээр офлайн нээгдэнэ.
- Явахын өмнө Wi-Fi-тай газар аппаа нээж, «N файл энэ утсанд хадгалагдсан» гэж харагдаж байгааг шалгаарай.

## Зураг

Үзэх газар бүрт Wikipedia-гийн зураг автоматаар гарна (Хятадад Wikipedia хаалттай тул Монголд байхдаа нэг нээхэд утсанд хадгалагдана). Газар дээр «Засах» → «Өөрийн зураг» дарж өөрсдийн зургийг нэмж болно.

## 27-ны өдөр: Хотоор эсвэл Дисней

Өнөөдөр хэсэгт 27-ны өдөр хоёр төлөвлөгөө харагдана. Хүн бүр «Би энэ төлөвлөгөөгөөр явна» дарж сонгоно, хэн аль нь болохыг аватараар харна.

## Нууц Санта 🎅

- 12-р сарын 28-ны 09:00-д (Шанхайн цагаар) сервер хүн бүрт нэг найзыг санамсаргүй сугална, хэн ч өөрийгөө сугалахгүй. Бүгдэд мэдэгдэл очно.
- Өнөөдөр хэсэгт бэлэгний хайрцгийг дарж задлахад хэнд бэлэг бэлдэхээ харна. Анх нээсэн утсандаа түгжигдэнэ: өөр утаснаас тэр хүний Сантаг харж чадахгүй.
- Хүн бүр урьдчилж «Хүсэл» бичнэ, «Бэлэг бэлэн» тэмдэглэнэ. Хэмжээ, огноог Баг → Нууц Санта → Хэмжээ, огноо дээр сольно.
- 1-р сарын 1-ний 00:00-оос (Пхукетийн цагаар) хэн хэнийх байсныг бүгд харж болно.

## Мэдэгдэл

- Даваа, лхагва, баасан 09:00 (УБ): аялал хүртэл хэдэн хоног үлдсэн, хөгжилтэй үгтэй. Баасан гаригт «үдэшлэгт битгий яв, мөнгөө хадгал».
- Найз зардал нэмэхэд бусад нь мэдэгдэл авна.
- 1-р сарын 1, 00:00 Пхукетийн цагаар: шинэ жилийн мэндчилгээ.
- Аяллын өдөр бүр 08:00 (орон нутгийн цагаар): өдрийн төлөвлөгөө.

Хүн бүр апп дотроо **Баг → Мэдэгдэл асаах** дарна. **Баг → Хуваарь, илгээсэн** дээр удахгүй очих мэдэгдэл бүрийг яг үг, цагтай нь харж, «Надад одоо илгээх» дарж өөрийн утсан дээр урьдчилж үзнэ. «Илгээсэн» хэсэгт аль хэдийн очсон мэдэгдэл, хэдэн утсанд хүрснийг харуулна. **iPhone** дээр эхлээд Safari-ийн Share → **Add to Home Screen** хийж, нүүр дэлгэцийн Tripp дүрсээр нээсний дараа асаана (iOS 16.4+). Android дээр Chrome-оор шууд асна.

Илгээдэг нь Supabase дээрх `tripp-push` функц (`supabase/functions/tripp-push`), цагийг `pg_cron` барина. Тохиргоо нь `setup-push.sql`-д бий; аль хэдийн ажиллуулсан.

## Шинэчлэх

GitHub → энэ repo → **Add file → Upload files** → бүх файл, `icons` хавтсыг чирж оруулна → **Commit changes**. Нэг минутын дараа https://enkhjint23.github.io/tripp/ шинэчлэгдэнэ. Хуучин `icon.svg`-г устгаж болно.

Хуучин хувилбартай ижил өгөгдөл, ижил урилгын холбоос ашигладаг тул найзууд дахин нэгдэх шаардлагагүй.

## Хамгаалалт

Аяллын код зөвхөн урилгын холбоос дотор байдаг 22 тэмдэгттэй нууц. Урилгын холбоостой хэн ч аяллыг харж, засаж чадна, тиймээс зөвхөн бүлэгтээ илгээгээрэй.
